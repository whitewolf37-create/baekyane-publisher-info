처리하는 정보와 목적

운영자가 동의한 YouTube 채널 식별정보와 영상 정보는 올바른 채널 확인 및 중복 게시 방지에 사용합니다. 앱에서 사용하는 Google Drive 영상 파일은 게시할 원본을 보관하고 YouTube에 전송하는 데 사용합니다. Drive 전체 파일 접근 권한은 요청하지 않습니다.

보관과 서비스 제공자

원본 영상은 운영자의 비공개 Google Drive에 보관합니다. 소개글과 게시 진행 기록은 운영자의 비공개 GitHub 저장소에서 관리합니다. 계정 연결정보는 로컬의 접근 제한 폴더와 GitHub의 암호화된 Secret에 보관하며, 공개 코드나 실행 로그에 넣지 않습니다. Google과 GitHub는 인증·보관·자동 실행을 위한 서비스 제공자로 사용합니다.

공개와 이용 제한

공개되는 데이터는 운영자가 게시를 승인한 영상과 소개글입니다. 인증정보와 원본 보관 폴더는 공개하지 않습니다. Google API에서 받은 정보를 판매하거나 광고 타기팅, AI 모델 학습에 사용하지 않습니다. Google API 정보의 이용은 Google API 서비스 사용자 데이터 정책 및 제한된 사용 요건을 따릅니다.

연결 해제와 삭제

운영자는 Google 계정 연결 관리에서 앱 권한을 취소할 수 있습니다. GitHub 자동 실행을 중지하고 Secret을 삭제하면 새 인증 연결을 차단할 수 있습니다. 보관 파일과 진행 기록은 운영자가 Drive와 GitHub에서 직접 삭제할 때까지 유지됩니다. 이미 YouTube에 공개한 영상은 채널에서 별도로 관리합니다.
